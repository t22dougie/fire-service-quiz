# Fire Service College Quiz

A shareable React/Vite quiz app for Fire Service College revision.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This project includes a GitHub Actions workflow for GitHub Pages.

1. Upload the project to a GitHub repository called `fire-service-quiz`.
2. Go to Settings > Pages.
3. Set Source to GitHub Actions.
4. Push to the `main` branch.

Live URL will be:

```text
https://YOUR-USERNAME.github.io/fire-service-quiz/
```

## Add questions

Edit:

```text
src/questions.js
```
